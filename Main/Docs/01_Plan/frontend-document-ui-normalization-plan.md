# 문서 화면 UI 정규화 계획

## 목표

공유 문서 목록과 문서 편집기 화면을 기존 코밋툴 화면의 `Noto Sans KR`,
80% 스케일 기반 디자인 토큰, 간격 체계에 맞춰 일관되게 정리한다.

## 작업 범위

### 1. 공유 문서 목록

- 페이지 제목, 설명, 상단 버튼 크기를 팀 스페이스의 다른 화면과 통일
- 통계 카드의 높이·패딩·글자 크기와 긴 날짜 말줄임 처리 보완
- 검색창·정렬 선택창의 높이와 글꼴 크기 통일
- 문서 행의 아이콘·제목·메타 정보·액션 버튼 비율 조정
- 화면 폭에 따른 반응형 레이아웃 및 넘침 방지

### 2. 문서 편집기

- 상단 제목·권한·목록 이동 버튼을 목록 화면과 같은 비율로 통일
- 문서 메타 카드의 높이·폰트·간격 정리
- 제목 입력, 참여자, 연결 상태 영역의 시각적 위계 정리
- 툴바 버튼 크기와 그룹 간격 통일
- 본문 기본 글꼴, 제목 단계, 문단 간격, 목록·인용문·코드 스타일 정리
- 편집 영역의 최소 높이와 반응형 패딩 보완

### 3. 공통 원칙

- API, store, Yjs 실시간 동기화 로직은 변경하지 않음
- 기존 전역 디자인 변수(`--blue`, `--line`, `--text`, `--muted`) 재사용
- 고정 픽셀 확대가 아니라 현재 앱의 80% 스케일 체계에 맞춤
- 1440×810 기준으로 주요 정보가 과도한 스크롤 없이 보이도록 조정

## 검증

- `localhost:5173` 및 `70.12.245.45:5173`에서 목록 화면 확인
- 문서 생성·열기·삭제 동작 유지 확인
- 문서 제목 및 본문 실시간 동기화 유지 확인
- 1440×810과 좁은 화면에서 잘림·겹침·가로 스크롤 확인
- `npm run build` 성공 확인
