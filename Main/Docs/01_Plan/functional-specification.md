# 기능 명세서 (Functional Specification)

## 1. 개요 및 용어

### 1.1 서비스 개요
실시간 화상회의를 중심으로 팀 협업을 지원하는 플랫폼이다. 팀 스페이스 단위로 멤버가 모여 화상회의를 진행하고, 회의 중 실시간 채팅과 Markdown 문서 공동 편집을 수행하며, 회의 종료 후 AI가 회의록을 자동 생성한다.

### 1.2 용어 정의
| 용어 | 정의 |
| --- | --- |
| 팀 스페이스(Team Space) | 멤버·회의·문서·일정이 소속되는 협업 단위 |
| 회의(Meeting) | 팀 스페이스 내에서 생성되는 화상회의 세션 |
| 호스트(Host) | 회의를 시작·종료하고 참여자를 관리하는 권한 보유자 |
| SFU | Selective Forwarding Unit. 참여자별 미디어 트랙을 서버가 선택적으로 중계하는 미디어 서버 구조 |
| 회의록 | 회의 종료 후 전사·채팅·공동 문서를 기반으로 AI가 생성하는 정리 문서 |

### 1.3 우선순위 범례
| 표기 | 의미 |
| --- | --- |
| MVP | 1차 필수 구현 |
| 2차 | MVP 이후 구현 |
| Extra | 여력이 있을 때 구현하는 부가 기능 |
| TBD | 우선순위/포함 여부 미정 (팀 논의 필요) |

### 3.3 멤버 및 권한 (MEMBER)

역할은 MVP에서 지나치게 세분화하지 않는다. `Maintainer`는 Owner와 구분되는 권한이 확정될 때 추가한다.

| 역할 | 권한 |
| --- | --- |
| Owner | 스페이스 수정, 초대, 강퇴, 역할 변경, 회의 관리 |
| Member | 회의 생성·참여, 문서 편집, 회의록 조회 |
| Guest | 초대된 회의 참여 및 허용된 문서 열람 |

| ID | 기능 | 설명 | 우선순위 |

| MEMBER-02 | 멤버 초대 | 이메일 또는 초대 링크로 멤버를 초대한다 | MVP |

| MEMBER-04 | 멤버 강퇴 | Owner가 멤버를 스페이스에서 제외한다 | MVP |

## 8. 2차 기능

### 8.1 화이트보드
- 캔버스 생성 및 참여
- 도형·펜·텍스트·지우개
- 오브젝트 동시 편집
- 이미지 첨부
- 자동 저장
- PNG/SVG 내보내기
- 회의와 결과물 연결

> **Note.** Excalidraw를 사용하더라도 동기화·저장·접근 권한·이미지 업로드는 별도 구현이 필요하다.

### 8.2 일정
- 월·주·일 캘린더 조회
- 일정 생성·수정·삭제
- 담당자·마감일 지정
- 회의 및 회의록 연결
- AI가 추출한 일정 후보 표시
- 사용자 승인 후 일정 생성
- 중복 일정 경고

> **Note.** AI가 일정을 직접 등록하지 않고 `후보 추출 → 사용자 검토 → 확정` 흐름을 적용한다.

## 부록 C. 노션 원문 대비 정리 변경 이력

문서화 과정에서 **기능의 의미·범위는 유지**하되, 정식 명세서 형태로 다음을 조정했다.

| 변경 | 무엇을 | 왜 |
| --- | --- | --- |
| ID 체계 통일 | 노션에서 2장·3장이 모두 `R-1~R-5`로 중복 → 팀 스페이스 기능을 `SPACE-`로 재부여(목록 `SPACE-01~`, 관리 `SPACE-10~`) | 동일 ID 중복은 추적·참조 시 혼동을 유발하므로 도메인 프리픽스로 유일화 |
| 화상회의 분리 | `MEET`(회의 생명주기)와 `RTC`(실시간 미디어)를 별도 소절로 구성 | 원문에서 두 성격이 한 표에 섞여 있어 담당·구현 단위 구분을 명확히 함 |
| 미정 항목 표기 | 우선순위가 비어있거나 `?`이던 항목(팀 스페이스 채팅, 전용 닉네임 등)을 `TBD`로 명시 | 누락이 아닌 "미결정"임을 문서상 분명히 하기 위함 |
| 사이드바 메모 통합 | 흩어져 있던 사이드바/일정/멤버/회의·문서 목록 메모를 `SPACE-15~18`로 표에 편입 | 개별 메모를 정식 기능 항목으로 승격해 누락 방지 |
| 보충 설명 재배치 | 비밀번호 재설정 2차 사유, SFU 트랙 식별, Excalidraw 유의사항 등을 각 표 하단 Note로 이동 | 표는 항목 위주로 간결하게, 근거·주의사항은 인접 노트로 분리 |
| 빈 행·빈 셀 제거 | 노션 표의 빈 행과 미완성 셀 삭제 | 렌더링·가독성 개선 |
| 결정사항 표로 정리 | "우선 확정할 결정" 9개 항목과 확정 답변을 결정 표(§10)로 통합, 템플릿/스키마는 부록으로 분리 | 확정 정책을 한눈에 보이게 하고 긴 코드 블록을 본문에서 분리 |
| NFR의 수치 참조화 | 회의 규모·동시 처리 수치를 §10 결정과 연결 | 결정사항(결정 1)과 NFR 간 수치 불일치를 방지하기 위해 단일 출처로 참조 |
