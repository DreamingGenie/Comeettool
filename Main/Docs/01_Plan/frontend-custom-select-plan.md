# 전역 Custom Select 전환 계획

## 목표

- 네이티브 `<select>`를 앱 공통 커스텀 Select로 교체한다.
- 선택창뿐 아니라 펼쳐진 옵션 목록도 둥근 카드 UI로 완전히 통일한다.
- 기존 데이터 타입, `v-model`, API 동작과 접근성을 유지한다.

## 공통 컴포넌트

`Main/Frontend/src/shared/components/AppSelect.vue`를 추가한다.

### 지원 기능

- `v-model` 양방향 바인딩
- 문자열·숫자·null 값 타입 보존
- 동적 options와 disabled option
- 전체 컴포넌트 disabled 상태
- placeholder와 `aria-label`
- 선택 시 `change` 이벤트
- 클릭 및 Enter·Space로 열기
- 위·아래 방향키로 옵션 이동
- Enter로 선택, Escape로 닫기
- 바깥 영역 클릭 시 닫기
- 현재 선택값과 키보드 활성 항목 표시
- `role="combobox"`, `role="listbox"`, `role="option"` 적용

## 펼침 패널 UI

- 패널 모서리: `14px`
- 내부 옵션 모서리: `10px`
- 외곽선: 연한 블루 그레이
- 배경: 흰색
- 옵션 기본 배경: 흰색 또는 연한 회색
- hover·키보드 활성 배경: 연한 블루 퍼플
- 선택된 옵션: 체크 표시와 강조색
- 최대 높이 초과 시 내부 스크롤
- 넓고 옅은 그림자

## 위치 처리

- 표나 모달의 `overflow: hidden`에 잘리지 않도록 옵션 패널을 `body`로 Teleport한다.
- 버튼 위치를 기준으로 패널의 좌표와 너비를 계산한다.
- 화면 아래 공간이 부족하면 위쪽으로 펼친다.
- 창 resize·scroll 시 위치를 갱신한다.

3. 회의록·AI 자료 정렬
4. 프로필 연령대 선택
5. 프로필 직군 선택

## 기존 동작 보존

- 프로필 직군 변경 시 세부 직무 초기화
- 정렬 조건 변경
- 멤버 권한 및 직무 저장
- Owner 이전 대상 선택
- 새 회의 팀 스페이스 선택
- disabled 및 빈 옵션 처리
