# 캘린더 및 멤버 초대 UI 개선 계획

## 목표

- 팀 일정 캘린더를 밝은 블루 퍼플 중심의 차분한 색상 체계로 정리한다.
- 멤버 표 카테고리의 가독성을 높인다.
- 사용자 검색 드롭다운을 입력창과 자연스럽게 이어지는 카드형 UI로 개선한다.

## 작업 범위

### 1. 팀 일정 캘린더 색상

- 캘린더 제목: 밝은 블루 퍼플 계열(`#7086e8` 전후)
- 외곽선: 채도가 낮은 연한 블루 계열
- 그림자: 넓고 옅은 푸른 회색 그림자
- 요일 헤더와 셀 구분선: 연한 블루 그레이 계열
- 이전·다음 월 버튼: 기본 상태는 흰색, hover 상태는 블루 퍼플 강조
- 기존 이벤트 색상과 기능은 유지한다.

대상 파일:

- `Main/Frontend/src/features/board/components/BoardCalendar.vue`
- 필요한 경우 기존 전역 캘린더 CSS의 중복 색상 규칙 정리

### 2. 멤버 표 카테고리 가독성

- 표 헤더 카테고리 글자: `10px`에서 `12px`로 확대
- 헤더 높이와 좌우 정렬은 현재 테이블 구조를 유지한다.
- 본문 정보보다 헤더가 과하게 강조되지 않도록 색상과 굵기를 조정한다.

대상 파일:

- `Main/Frontend/src/features/board/views/MembersView.vue`

### 3. 사용자 검색 드롭다운

- `이름 또는 이메일` 라벨: `10px`에서 `13px`로 확대
- 검색 입력 글자: `12px`에서 `14px`로 확대
- 검색 결과 패널을 입력창 너비에 맞춘 흰색 외곽 카드로 구성
- 결과 한 건을 연한 회색 배경의 내부 카드로 표시
- 아바타: `32px`에서 `44px`로 확대하고 블루 퍼플 계열 적용
- 사용자 이름: `14px`, 이메일: `12px` 수준으로 계층 구분
- hover·focus-visible 상태와 키보드 접근성을 유지한다.
- 검색, 사용자 선택, 초대 API 동작은 변경하지 않는다.

대상 파일:

- `Main/Frontend/src/features/board/components/InviteModal.vue`

## 검증

1. 멤버 초대 모달에서 검색 결과의 이름·이메일·아바타 배치 확인
2. 결과 선택과 초대 전송 기능 회귀 테스트
3. 멤버 표 헤더 가독성 확인
4. 홈 및 팀 스페이스 캘린더 색상 일관성 확인
5. 반응형 화면과 프론트엔드 빌드 확인

- 멤버 권한 및 초대 비즈니스 로직 변경
